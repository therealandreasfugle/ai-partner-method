# /marketing-sop — Marketing & Sales Doctrine

Routes any marketing/sales task to the right framework in `frameworks/` and follows it.

## Workflow

1. **Ask what the user is trying to do.** Pick the right framework(s):
   - **Write a VSL** → `frameworks/vsl_sop.md` + `playbook/Hooks_Openers.md` + `playbook/Pricing_Value_Framing.md` + `playbook/CTAs.md`
   - **Design a webinar (full funnel)** → `frameworks/webinar_funnel_sop.md`
   - **Design the slides/script** → `frameworks/webinar_presentation_sop.md`
   - **Set up WebinarJam** → `frameworks/webinarjam_setup_guide.md`
   - **Build an interactive lead magnet** → `frameworks/interactive_lead_magnet_sop.md` + `playbook/Lead_Magnets.md`
   - **Set up a ManyChat follow-gate flow** → `frameworks/manychat_follow_gate.md`
   - **Audit / write sales copy** → `frameworks/copywriting_frameworks.md` + relevant `playbook/` files
   - **Design an offer** → `playbook/Offers_Funnels.md` + `playbook/Pricing_Value_Framing.md` + `playbook/Named_Frameworks.md`
   - **Build cold ads** → `playbook/Ad_Strategy.md` + `playbook/Hooks_Openers.md` + `playbook/Anti-Positioning.md`
   - **Sales call frameworks** → `playbook/Sales_Call_Qualifier.md` + `playbook/Contrarian_Reframes.md`
   - **Authority + content strategy** → `playbook/Authority_Building.md` + `playbook/Content_Structure.md` + `playbook/Story_Origin.md`
   - **Scaling to $100K+ / mo** → `playbook/Scaling_Operations.md` + `playbook/Mindset_Identity.md`
   - **Study a high-converting webinar** → `case-studies/`

   See `playbook/README.md` for the full lookup index across all 17 playbook categories.

2. **Read the full framework** before producing anything. These docs are the doctrine — follow them exactly. Don't generalize from your training data when there's a specific framework here.

3. **Ask for the inputs the framework requires.** Most frameworks need:
   - The offer (what's being sold, price, format)
   - The avatar (who buys it — pull from a `/client-dossier` output if available)
   - The current funnel state (what already exists)
   - Any past copy / scripts to work from

4. **Produce the output.** Match the format the framework prescribes (slides → slide-by-slide script, VSL → 60-min script in beats, lead magnet → Lovable build spec, etc.).

5. **Cross-reference case studies** when relevant. The Scott Kelly and Shelby Sapp breakdowns are live examples of every principle in action.

## Hard rules

- **Don't paraphrase the doctrine.** Read the framework, follow the framework. These were built from real swipe files and live tests.
- **Pull audience language from real source data**, not your imagination. If you don't have a dossier, ask the user for one or for transcribed sales calls / DMs / comments.
- **Cite which framework section you're applying** as you produce output, so the user can verify against the source.
- **Flag uncertainty.** If the user's offer doesn't fit the framework cleanly, say so and ask before proceeding.
